One session plans. One does the work. You stay in charge.

MushrifLoop is an orchestrator for Claude Code: a Windows desktop app that runs a coding task as a supervised loop between two sessions on your own computer. It passes each step across, holds the limits, and stops to ask whenever a decision is yours.

Download for Windows Source on GitHub

Free and open source · Windows 10/11, x64 · needs Claude Code 2.1.251 or newer

How it runs

One step at a time, and every step reviewed.

A task does not go to one session to finish alone. It goes round a loop, and the loop has an owner.

  1. The Planner decides

    It reads the task and your project, and writes one instruction for the next step. It never touches your files.

  2. The Executor does it

    It carries out that one step in your project folder, then reports what it changed and what it ran.

  3. The Planner reviews

    It checks the report against the task. Then comes the next step, or the end, or a question for you.

What you get

Supervision, built into every step.

The same Claude Code you already use, with an owner for the loop.

  • SupervisionEvery instruction can be read and approved before it reaches the Executor.
  • A review of every stepA second session checks each result against the task before the next step starts.
  • CoordinationThe app moves the work between the two sessions, and handles context, limits and handoffs itself.
  • Follow-upA timeline of every cycle, a commit per cycle, and the full record of every turn.
  • Your timeA long task runs unattended and calls you only when a decision is yours.

Between them

The app holds the limits, so the agents don't have to.

None of this is left to the models. The orchestrator enforces it from outside the two sessions.

  • ApprovalsRun unattended, read every instruction before it is sent, or approve one full plan first.
  • A cycle capA task stops at the number of cycles you set.
  • Turn timeoutsA turn that runs too long is stopped, with its whole process tree.
  • Loop detectionThe same step going round again is caught, and the task stops.
  • A commit per cycleOn a branch of its own. Your branch is left as it was.
  • Account checksYou see which Claude account a turn would run on before it runs.
  • Usage limitsWhen a limit is reached the task pauses with both sessions kept, to continue after the reset.
  • A full recordEvery instruction, every report and the CLI's raw output are saved on your machine.

Plainly

What it costs.

It depends on the size of the task, and on what you compare it with.

In our first measurements, with the Planner on Opus and the Executor on Sonnet, small and medium tasks cost about a quarter less than a plain Opus session. Large tasks cost a little over twice as much.

Against a plain Sonnet session it cost more at every size. The Planner is the small part of the bill: about 6% on large tasks.

It takes longer than a plain session, nearly twice as long on large tasks, but it does not need you while it runs. The three finished the medium and large tasks equally well.

Early numbers: 22 tasks, one run each. The full benchmark is under way and will be published here, whatever it says.

Install

Download, run, and it checks the rest.

  1. Install Claude Code and sign in, if you have not already.
  2. Download the installer or the portable exe from the Releases page.
  3. Run it. First-run setup checks that Claude Code is present, new enough and signed in before it lets you start.

Windows will warn you

The installer is not code-signed yet, so SmartScreen says "Windows protected your PC". Choose More info, then Run anyway. Each release lists the SHA-256 of its files. Check your download with: 

certutil -hashfile <the file you downloaded> SHA256

Your data

Everything stays on your machine.

MushrifLoop never talks to the Anthropic API itself.

  • Your own accountEvery turn is an ordinary claude process, unmodified, under whoever is signed in to Claude Code. The app has no account, key or billing of its own.
  • No telemetryThe app collects nothing. The one network request it makes itself asks the npm registry for the latest Claude Code version.
  • Local filesTasks, settings and logs live in %APPDATA%\MushrifLoop, and stay there when you uninstall unless you choose otherwise.
